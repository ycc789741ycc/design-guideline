# Glossary

Shared vocabulary for domain terms and acronyms. Keep terms here consistent
across backend, frontend, docs, and code — the same concept should have the
same name everywhere.

| Term | Definition |
|---|---|
| _Example: Customer_ | _A person or overrides with an active account. Not "client" or "user" — use "customer" everywhere._ |
| _Example: Order_ | _A confirmed purchase. A cart that hasn't been checked out is a "cart," not an "order."_ |

Replace the examples with your overrides' actual domain terms as they're
established. This file should grow as ambiguity comes up in review — if two
people/AI outputs use different words for the same thing, that's the signal
to add an entry here.
